# Авто-гід 2026

Довідник вживаних авто для **французького ринку** (Île-de-France, 2026): 201 модель, 29 марок (без мінівенів), SUV і 4x4, ціни 7–20 k€, характеристики (hp, Nm, 0–100, витрата, багажник, маса), 12 топів, мотори (TSI, TFSI, Skyactiv-G, Hybrid…), коробки (Manual 6 / BVM6, DSG, EDC, EAT8…), ціни в k€, надійність, відгуки власників, порівняння, витрати першого року.

Статичний сайт: чистий HTML + CSS + JS, без збірки й залежностей. Працює і з GitHub Pages, і просто подвійним кліком по `index.html`.

## Як опублікувати на GitHub Pages

1. Створи новий репозиторій на github.com (наприклад `autogid-2026`), Public.
2. Натисни **Add file → Upload files** і перетягни **вміст** цієї папки (не саму папку): `index.html`, `site.webmanifest`, `.nojekyll`, `README.md`, папки `assets` і `data`.
   - Файл `.nojekyll` на Mac прихований: у Finder натисни `Cmd + Shift + .`, щоб його побачити. Він не обов'язковий, але бажаний.
3. **Commit changes**.
4. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch: `main`, папка `/ (root)` → **Save**.
5. Через 1–2 хвилини сайт буде на `https://<логін>.github.io/autogid-2026/`.

Через термінал:

```bash
cd autogid-2026
git init && git add . && git commit -m "Авто-гід 2026"
git branch -M main
git remote add origin https://github.com/<логін>/autogid-2026.git
git push -u origin main
```

## Структура

```
index.html            сторінка
assets/style.css      стилі (світла і темна тема автоматично)
assets/app.js         логіка: фільтри, порівняння, графік, калькулятор
assets/favicon.svg    іконки
data/models.js        база моделей (window.MODELS)
data/content.js       топ-12, топ SUV/4x4, марки, таблиця моторів, словник FR
data/interior.js      якість салону 1–5 і коротко про матеріали (window.INTERIOR)
data/photos.js        фото зовні й салону з Wikimedia Commons (window.PHOTOS)
site.webmanifest      «Додати на головний екран» на телефоні
```

## Як редагувати дані

Кожна модель у `data/models.js` — один рядок:

| Поле | Що це |
|---|---|
| `b`, `m`, `g`, `y` | марка, модель, покоління, роки |
| `s` | кузов: `A`, `B`, `C`, `D`, `SUV-B`, `SUV-C`, `SUV-D`, `4x4`, `Sport` |
| `p` | ціна 2026 від–до в k€; `pe: 1` — оцінка |
| `r` | надійність 1–5 |
| `t` | `top`, `ok`, `risk`, `avoid` |
| `m4` | 1, якщо є надійна версія Manual + 4-cyl petrol |
| `e` | мотори; перший символ: `+` надійний, `~` з нюансами, `-` уникай |
| `gb`, `w`, `rv`, `chk`, `best`, `v` | коробка, слабкі місця, відгуки, що перевірити, яку версію брати, вердикт |
| `sp` | характеристики еталонної версії: [версія, hp, Nm, 0–100 s, l/100 km, довжина mm, багажник l, маса kg] |
| `awd`, `f`, `tr` | є 4x4/AWD; пальне еталону (P/D/H); коробка еталону (M/A) |

Салон — `data/interior.js`, ключ — `id` моделі: `[оцінка 1–5, "текст"]`. 5 — м'які матеріали майже скрізь, 3 — м'який верх панелі, решта твердий пластик, 1 — дешевий пластик, що скрипить.

Фото — `data/photos.js`, ключ — `id` моделі: `[["e" або "i", "шлях/файлу.jpg", "автор", "ліцензія", рік], …]`. `e` — зовні, `i` — салон. Шлях — частина адреси файлу на `upload.wikimedia.org/wikipedia/commons/` (наприклад `9/95/Name.jpg`). Брати тільки файли з Wikimedia Commons з вільною ліцензією (CC0, CC BY, CC BY-SA, суспільне надбання): автор і ліцензія показуються під фото.

Кожна модель має свою сторінку: `index.html#model/<id>` (усі мотори, коробки, салон, фото, альтернативи). Посилання можна надсилати.

Фільтри, бюджет і список порівняння зберігаються в браузері (localStorage).

Ціни — орієнтовні (листопад 2026), перевіряй в актуальних оголошеннях.
